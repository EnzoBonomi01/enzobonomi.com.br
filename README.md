# Site de Portfólio - Enzo Bonomi

Este é o site de portfólio profissional do Enzo Bonomi, desenvolvido com HTML, CSS e JavaScript puro.

## Estrutura de Pastas

```
enzo-portfolio/
├── index.html              # Página principal
├── README.md               # Este arquivo
├── assets/                 # Recursos do site
│   ├── images/            # Imagens
│   │   └── enzo-photo.jpg # Foto de perfil
│   └── documents/         # Documentos
│       ├── Enzo Bonomi Perfil.pdf   # CV em português
│       └── Enzo Bonomi Profile.pdf  # CV em inglês
├── css/                   # Estilos
│   └── styles.css         # CSS principal
└── js/                    # Scripts
    └── script.js          # JavaScript principal
```

## Funcionalidades

✅ **Design Responsivo** - Funciona em desktop, tablet e mobile
✅ **Modo Escuro/Claro** - Toggle entre temas
✅ **Tradução PT/EN** - Seletor de idioma que traduz todo o conteúdo
✅ **Download de CV** - Botão que baixa o CV no idioma selecionado
✅ **Seções Completas**:
   - Apresentação pessoal com foto e informações
   - Experiência profissional com timeline (incluindo Stone Co. e Influx English School)
   - Projetos realizados
   - Habilidades técnicas e soft skills
   - Certificações
   - Formulário de contato

## Como Usar

1. **Para visualizar localmente:**
   - Extraia todos os arquivos mantendo a estrutura de pastas
   - Abra o arquivo `index.html` em qualquer navegador web

2. **Para hospedar online:**
   - Faça upload de todos os arquivos e pastas para seu provedor de hospedagem
   - Mantenha a estrutura de pastas intacta
   - Configure o `index.html` como página inicial

3. **Para personalizar:**
   - Edite o `index.html` para alterar conteúdo
   - Modifique o `css/styles.css` para ajustar cores e layout
   - Atualize o `js/script.js` para adicionar novas funcionalidades
   - Substitua as imagens em `assets/images/`
   - Atualize os documentos em `assets/documents/`
