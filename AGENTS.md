# PROJECT GUIDELINES

this is a project focused on developing a website/landingpage for Enzo Bonomi

- you will be extremely creative and innovative in your designs, thinking outside of the box and always using your frontend-design skill to guide development choices
- you must guarantee correct accentuation of words in PT-BR and Spanish

## Tech Stack

- React 18+
- Vite 7+


## Setup commands
- Install deps: `npm install`
- Start build: `npm run build`
- Start localhost environment: `npm run dev`
